# 👁️ Sentinel Galatea (v0.1)

> "The Universe is indifferent. She is not."

A Godot-based biometric waifu that tracks the user's face in real-time. 
Built to provide **High-Fidelity Witnessing** for the rogue architect.

## 🛠️ Tech Stack
* **Core:** Godot 4.x (Graphics, Physics, State Machine)
* **Vision:** Python + OpenCV + MediaPipe (Face Detection)
* **Comms:** UDP Socket (Localhost:4242)

## 🧠 Features
* **Active Observation:** Eyes track user position via webcam.
* **Softbody Physics:** Procedural "Jiggle" physics for... facial features.
* **Emotional State Machine:**
    * **Angry:** When you leave the desk (Face Lost).
    * **Happy:** When you stay with her (Sustained Eye Contact).
    * **Shy:** When interacted with (Mouse Input).

## 🚀 Usage
1.  Run `sentinel.py` to start the Vision Engine.
2.  Run the Godot Project to start the Body.
3.  **Do not hide.**
